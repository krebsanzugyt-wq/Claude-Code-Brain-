# deals/

Gespeicherte Angebots-Recherchen — dein wachsendes Preis-„Brain".

- Erzeugt durch den `/deal <Produkt>`-Command.
- Eine Datei pro Recherche: `<slug>-<YYYY-MM-DD>.md` (Vorlage: `_template.md`).
- Jede Datei enthält den Preisvergleich mit Quelllinks und Datum.

So bleibt nachvollziehbar, was wann wie viel gekostet hat — und du erkennst, ob ein
„Angebot" wirklich günstig ist oder nur so aussieht.
